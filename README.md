# SiteScope

Пассивный внешний аудит сайта с графическим интерфейсом на Python (tkinter).

Проверяет доступность и HTTPS, TLS-сертификат, защитные HTTP-заголовки, флаги cookie, формы (mixed content, пароли в GET), DNS, публичные `robots.txt` / `sitemap.xml` / `security.txt` и ограниченный список служебных путей (`.env`, `.git/HEAD`, бэкапы). Активные payload-запросы не отправляются: SQLi, XSS и другие инъекции намеренно не тестируются. Отчёт сохраняется в `.docx`.

## Требования

Windows, Python 3.10+. Внешних зависимостей нет.

## Запуск

```
python site_audit.py
```

## Ограничения

Запускать только для сайтов, которыми владеете или на анализ которых есть разрешение. Локальные и частные IP-адреса блокируются. Результаты — ориентировочный обзор, а не подтверждение отсутствия уязвимостей и не замена полноценному аудиту.
